Cheat sheet
. any character
[abc] one of a, b, c
[^abc] anything but a, b, c
[a-z0-9] ranges
\d \w \s digit, word char, space
\D \W \S the opposites
* + ? 0+, 1+, 0 or 1
{3} {2,5} {2,} counts
*? +? lazy (as few as possible)
^ $ start, end
\b word boundary
a|b a or b
( ) group and capture
(?: ) group, no capture
\1 repeat group 1's text
$1 group 1 in a replacement
(?= ) (?! ) lookahead yes / no
(?<= ) (?<! ) lookbehind yes / no
\. \$ \( escape special characters
i m s flags: ignore case, multiline, dot-all
